### 2.2 Estrutura de Banco de Dados (`qa_test_accounts`)

A identificação das contas de teste é gerenciada no banco pela tabela isolada `public.qa_test_accounts`:

```sql
CREATE TABLE public.qa_test_accounts (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  user_id UUID UNIQUE NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,
  persona TEXT NOT NULL CHECK (persona IN ('client', 'provider', 'admin')),
  description TEXT,
  created_at TIMESTAMPTZ NOT NULL DEFAULT timezone('utc'::text, now())
);
```
